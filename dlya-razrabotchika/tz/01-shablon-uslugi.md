# Шаблон «Посадочная услуги» (14 блоков)

Образец: `verstka/shablon-uslugi.html` — все блоки по порядку с жёлтыми подписями (на рабочих страницах подписи удалить:
элементы `.tpl-note` и атрибут `data-tpl`). Блок без данных просто не выводится, соседние сдвигаются.

| № | Блок | Обязательный | Что внутри |
|---|---|---|---|
| 01 | Первый экран | да | Хлебные крошки, H1, лид, 4 плашки-преимущества, 2 кнопки, вертикальное фото |
| 02 | Подменю разделов | нет | Липкое меню-якоря; пункты = блоки, которые есть на странице |
| 03 | Кому подойдёт | нет | Заголовок, лид, 3–4 карточки (фото сверху — горизонтальные) |
| 04 | Почему К2 | нет | Фото на фон (для телефона своё, вертикальное), 3 цифры с подсчётом, 2 карточки, кнопка |
| 05 | Форматы и цены | да | 2–3 карточки формата (фото, бейдж, список, цена, кнопка) + плашка «Не знаете, что выбрать?» |
| 06 | Как проходит | нет | А: шкала времени (`data-total` — длительность в минутах, шаги `data-from`/`data-to`). Б: шаги-карточки |
| 07 | Видео | нет | А: один ролик (`data-video`, пусто — «Видео скоро»). Б: лента вертикальных роликов |
| 08 | Расписание | нет | Строки: группа · дни и время · подпись |
| 09 | Тренеры | нет | Карточки; по клику — окно с описанием (скрытый блок `.lp-coach__bio` в карточке) |
| 10 | Фотогалерея | нет | 7 фото, остальные по «Показать ещё», просмотр по клику. Ячейки 1, 5, 8 — вертикальные фото |
| 11 | Отзывы | нет | Виджет Яндекс Карт / 2ГИС |
| 12 | «Нужно связаться» | нет | Общий блок контактов с формой |
| 13 | Частые вопросы | да | 4–8 вопросов, первый открыт (нужен для поисковиков) |
| 14 | Финальный призыв | да | Заголовок, текст, кнопка с бегущей надписью |

Правило для фото: вертикальные снимки — только в вертикальные рамки, горизонтальные — в горизонтальные.
