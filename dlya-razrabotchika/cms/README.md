# Модель контента для админки

Папка для настроек CMS (шаблоны, поля, чанки). Клиент сам меняет тексты, цены, фото и даты — всё ниже должно быть полями.

| Сущность | Поля |
|---|---|
| **Курс / товар** (`kurs-*.html`) | название, краткое содержание, цена, старая цена, фото шапки (горизонтальное), обложка А4 (вертикальная), факты (тренировок, длительность, формат, снаряжение), текст описания (визуальный редактор), галерея, вопросы-ответы, «другие курсы» (подборка), макс. количество в одном заказе |
| **Мероприятие** | название, краткое содержание, дата начала, дата окончания (для диапазона), день недели и время, время начала, место сбора, для кого (дети / взрослые), стоимость участия, состояние (открыто / мест нет), **дата ухода в архив**, обложка А4, фото шапки, программа (время + пункт), кто может участвовать, что взять, текст, галерея; для архива — «как это было», итоги |
| **Сертификат** | название, номинал, цена, описание, список «что входит» |
| **Тренер** | фото (вертикальное), имя, должность, квалификация · стаж, о себе, специализация, с кем работает, достижения |
| **Посадочная услуги** | 14 блоков шаблона (см. `../tz/01-shablon-uslugi.md`); у каждого блока переключатель «показывать» |
| **Статья блога** | рубрика, теги, заголовок, лид, обложка, дата, автор, текст, связанные услуги |
| **Текстовая страница** (документы) | название, дата редакции, разделы (заголовок + текст) |
| **Настройки сайта** | телефон, часы работы, адрес, мессенджеры, ссылки на отзывы (Яндекс, 2ГИС, Google), реквизиты, ссылка на PDF прайса, вместимость зала |

Списки (мероприятия, архив, блог, тренеры) выводятся из этих записей автоматически; для поисковиков у «Показать ещё»
и пагинации архива нужна обычная постраничная навигация (`?page=2`).
