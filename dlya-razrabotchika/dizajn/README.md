# Дизайн-система

Все значения заданы переменными в начале `verstka/css/style.css` (`:root`).

## Цвета

| Переменная | Цвет | Где |
|---|---|---|
| `--graphite` | `#2D2D2D` | тёмные блоки, текст на светлом |
| `--graphite-deep` | `#202020` | фон страницы под блоками |
| `--graphite-raised` | `#3D3D3D` | карточки на тёмном |
| `--red` | `#D9493E` | акцент: кнопки, цены, иконки (нажатие — `--red-press` `#C23A30`) |
| `--grey-100` | `#E1E1E1` | светлые блоки |
| `--stone-100…600` | `#F1EFEC` → `#6B6762` | формы, подписи, линии |
| `--white` | `#FFFFFF` | карточки |

## Шрифты

- Заголовки, цифры: **Unbounded** (`assets/fonts/Unbounded.woff2`).
- Текст, кнопки: **Onest** (`assets/fonts/Onest.woff2`).

## Размеры текста (компьютер)

H1 56/64 · H2 40/48 · H3 28/34 · H4 20/26 · H5 16/22 · лид 20/30 · текст 16/24 · кнопки 15/20 · подписи 14/20 · мелкие 12/16 · цифры УТП 80/80.
На телефоне заголовки блоков крупнее обычного уменьшения (×1.3), на ширине ≤ 359 px — 24 px.

## Сетка и отступы

Контейнер 1280 px + поля 32 px · колонки — 12, промежуток 24 px · **отступ между блоками 112 px** (телефон 72 px; два блока одного цвета подряд — один отступ) ·
скругления 8 / 16 / 24 / 40 px.

## Точки перестройки

`≥ 1041 px` — компьютер · `≤ 1040 px` — планшет · `≤ 767 px` — телефон · `≤ 359 px` — узкий телефон.
Учитывается `prefers-reduced-motion` (анимации отключаются).
