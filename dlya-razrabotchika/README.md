# Скалодром К2 — материалы для разработчика

Здесь всё, что нужно, чтобы перенести сайт на рабочую платформу и подключить заявки, корзину и оплату.
Живая версия макета: https://korsh22.github.io/k2-site/

## Что в папке

| Папка / файл | Что внутри |
|---|---|
| [`verstka/`](verstka/) | Готовая вёрстка **всех страниц**: по одному HTML на страницу + общие `css/`, `js/`, `assets/` (фото, шрифты, документы). Без номеров версий и служебных пометок. Открывается в браузере как есть. |
| [`stranicy.md`](stranicy.md) | Список всех страниц: файл, заголовок, шаблон, ссылка на живую версию. |
| [`tz/`](tz/) | Технические задания и описание логики: шаблоны страниц, корзина, формы. |
| [`backend/`](backend/) | Что нужно сделать на сервере: заявки, заказы, оплата, промокоды, загруженность зала. |
| [`cms/`](cms/) | Модель контента для админки: какие поля у каждого шаблона (курс, мероприятие, тренер, статья…). |
| [`dizajn/`](dizajn/) | Дизайн-система: цвета, шрифты, размеры, сетка, точки перестройки. |
| [`foto/`](foto/) | Какие фото и тексты временные и что заменить перед запуском. |

## Как устроен макет

- Сайт статический: HTML + CSS + чистый JavaScript, без фреймворков и сборщиков.
- Стили: `css/style.css` (общие: шапка, подвал, кнопки, формы, главная), `css/landing.css` (внутренние страницы и шаблоны), `css/blog.css` (блог, статьи, текстовые страницы).
- Скрипты: `js/main.js` (главная), `js/landing.js` (внутренние страницы: окна, галереи, слайдеры, формы), `js/blog.js` (фильтры блога, меню), `js/search.js` (поиск по сайту), `js/cart.js` (корзина — на всех страницах).
- Тексты и цены на страницах — **примерные (рыба)**. Реальные даст скалодром; см. [`foto/`](foto/).
- Исходники генерации — в папке `tools/` репозитория (Python). Порядок сборки: `build_pages.py` → `build_blog.py` → `build_site.py`, затем `build_dev.py` обновляет эту папку. Для переноса на CMS генераторы не нужны — берите вёрстку из `verstka/`.

## Шаблоны страниц

1. **Главная** — `index.html`.
2. **Посадочная услуги** — универсальный шаблон из 14 блоков. Образец со всеми блоками и подписями: `shablon-uslugi.html` ([описание](tz/01-shablon-uslugi.md)).
3. **Товар** — базовый курс, сертификат, пакет (`kurs-*.html`) и **Мероприятие** (страницы мероприятий и прошедших мероприятий `arhiv-*.html`) — [описание](tz/02-tovar-i-meropriyatie.md).
4. **Магазин** — каталог `magazin.html` (фильтр по категориям) и страницы товаров на шаблоне «Товар» с выбором вариантов (размер, цвет, объём): `futbolka-k2.html`, `hudi-k2.html`, `meshochek-dlya-magnezii.html`, `butylka-k2.html`, `magneziya.html`, `shoper-k2.html`. В меню — внутри «О нас».
5. **Корзина** и **Спасибо** — `korzina.html`, `spasibo.html` — [описание](tz/03-korzina.md).
6. **Блог** (список и статья), **текстовая страница** (документы).

## Что подключить (коротко)

| Что | Где в вёрстке | Подробно |
|---|---|---|
| Заявки из форм (обратный звонок, запись, вопрос, отзыв, отклик на вакансию) | атрибут `data-action` у формы | [tz/04-formy.md](tz/04-formy.md) |
| Корзина → заказ → оплата банком → «Спасибо» | `js/cart.js`, `data-action` у `.cart__form` | [tz/03-korzina.md](tz/03-korzina.md), [backend/](backend/) |
| Промокоды | сейчас демо в `js/cart.js` | [backend/](backend/) |
| Загруженность зала («в зале») | `data-endpoint` у `#occ` | [backend/](backend/) |
| Архив мероприятий: событие уходит в «Прошедшие» по дате | поле «дата ухода в архив» | [cms/](cms/) |
| Поиск по сайту | `js/search.js` — статичный список страниц | заменить серверным поиском |

## Важно

- Ключи CRM, банка и других сервисов **никогда не кладём в код страниц** — только на сервере.
- Цены, скидки и промокоды в браузере — только для показа. Сумму заказа всегда пересчитывает сервер.
- Вёрстка адаптивная: проверена на ширине 320–1920 px и на невысоких экранах ноутбуков.
