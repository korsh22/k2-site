# Что временное и что заменить перед запуском

Папка для исходных фото и видео от скалодрома (большие исходники в репозиторий не кладём — только подготовленные для сайта).

## Фото

- **Тренеры** (`coach-1…4.jpg`) — фото-заглушки, не тренеры К2. Нужны вертикальные портреты тренеров.
- **`p-overhang.jpg`** — чужой кадр (El Capitan) с водяным знаком, стоит в блоке «Почему лазать в К2» на «О скалодроме». Заменить обязательно.
- Фото с префиксом `p-` — стоковые/временные; с префиксом `k2-` — снимки зала. Заменить на съёмку К2 по ТЗ фотографа.
- Правило: вертикальные снимки — только в вертикальные рамки (обложки А4, портреты), горизонтальные — в горизонтальные.

## Тексты и данные

- Все тексты описаний, цены, даты мероприятий, расписание, отзывы-подписи — **рыба** (примерные).
- Контакты в подвале и блоке связи (`hello@k2.example`, `ул. Скалистая, д. 13`, `+7 (812) 000-00-00`, ООО «Скалодром К2») — заглушки.
- Ссылки на отзывы (Яндекс, 2ГИС, Google) — `#`, нужны реальные.
- Видео — пока обложки с пометкой «Видео скоро» (`data-video` пустой).
- Промокоды в корзине — демо.
